To publish free with GitHub Pages:
1. Create a new GitHub repository (example: bubby-portal).
2. Upload index.html, style.css, app.js, and logo.jpeg from this folder.
3. In the repository, open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Choose the main branch and / (root), then Save.
6. GitHub will show the public link when deployment finishes.

Tip: On iPhone, open the published page in Safari > Share > Add to Home Screen.

To personalize later, edit the message arrays in app.js.
